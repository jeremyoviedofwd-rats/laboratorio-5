# Minecraft Hub

Proyecto desarrollado para el laboratorio de Git, Control de Versiones e IA aplicada.

## Descripción

Minecraft Hub es una página web inspirada en Minecraft que permite visualizar criaturas, bloques y administrar recursos del jugador.

## Funcionalidades

- Catálogo de criaturas.
- Inventario de bloques.
- Contador de recursos.
- Interacciones con JavaScript.
- Diseño inspirado en Minecraft.

## Tecnologías

- HTML5
- CSS3
- JavaScript
